### Decisions still open (ask the user at the start, briefly)

1. **Real photos vs cartoon characters.** The references use real photos. Options: embed cropped portraits from the refs as base64 `<image>` inside the SVGs (heavier files, and the deploy is already 7 MB), or keep `illus.py` characters restyled into the soft blob photo frames. Recommend the photos for hosts and keep the illustrations as onboarding heroes; confirm first.

Proposal: allow opacity and gradients built from existing tokens only, and log it as a README question for Rahul.

Use the reference layout with the user as the caller. The reference adds Message and Audio Only buttons that the brief doesn't have: keep them only if the brief or the user agrees.
4. **06 Live Photo for normal users:** this is new behaviour. The PRD has a liveness check only for hosts (08). Design the step for users, place it in the user flow after 06, and ask where exactly it goes and whether it blocks progress. Log it as a question.
